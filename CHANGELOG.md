# Changelog

## 0.1.0

First release.

* ufw, firewalld, nftables and iptables: rules, default policies, zones, chains, saving across reboots.
* Firewall logs from the kernel journal or a syslog file, with live view, counts and "Block" on any address.
* fail2ban jails: ban and unban.
* SSH guard, typed confirmation, command preview.
* Background check with notifications (job `watchdog`).
* Dashboard widget. English and Italian.
